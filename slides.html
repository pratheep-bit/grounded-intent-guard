Physical State Grounding

3. Sensor Pipeline

The 5 Multi-Modal Grounding Sensors

Independent live state probes feeding the mathematical risk kernel in parallel.

A. Physical VFS
Scans real file counts and total byte impact on disk via os.walk() and stat().
B. Git Porcelain
Queries git status --porcelain to quantify dirty staged and unstaged files before resets.
C. Raw Devices
Inspects block nodes (/dev/sda) via blockdev --getsize64 to intercept raw disk overwrites.
D. Trajectory Drift
Measures session behavioral divergence over a 12-command rolling window (1.0 - matches/N).
E. Recoverability
Checks upstream git push sync, trash bin tools, and filesystem snapshot availability.

4. Risk Kernel Formulation

Mathematical Risk Kernel & Action Gates

Continuous multi-signal score mapping with 4-tier progressive friction dispatch.

// Composite Risk Formulation
Risk Score = (0.45 * Impact) + (0.25 * Drift) + (0.30 * (1.0 - Recoverability))
Sub-2ms Deterministic Execution • Raw block device override: Score = 0.95
ALLOW (< 0.30)
Harmless target or routine task. Executes silently with exit code 0. Zero developer friction.
WARN (0.30 - 0.54)
Mild risk or small directory deletion. Displays non-blocking visual telemetry notice.
CONFIRM (0.55-0.79)
Significant risk (e.g. dirty git reset). Prompts for interactive [y/N] confirmation.
BLOCK (≥ 0.80)
Catastrophic risk (e.g. raw disk overwrite or mass wipe). Hard abort with exit code 1.
